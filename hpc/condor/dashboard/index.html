Actions

Submit / continue sweep Pulls the latest code on the access point, then submits every grid point that has no result yet. Points that are done or already queued are skipped. To rerun unconverged points, raise MAXITER first.
Remove held jobs Removes the held jobs of this sweep. Read their log first (click a red point), then press Submit to run them again.
Observables Submits one observables job for every stored state whose observables are missing or outdated (N_SAMPLES, N_EDGE below).
Phase-diagram plot Runs the plot script on the access point (κ, CV, |⟨a⟩|², ρ, S_bstd, phases), using KAPPA_TOL and CV_TOL below.
Gather data Copies this sweep's states, observables and plot from the access point to the data/ and plots/ folders on this laptop (only new or changed files).
Cancel sweep Removes every queued, running or held job of this sweep. Stored results are kept.
